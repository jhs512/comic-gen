설명 사이에, 작은 대화.

만화 코드 블록을 브라우저에서 렌더링합니다. 아래 카드를 클릭하면 원래 배치를 유지하는 만화 뷰어가 열립니다. 각각 독립적인 코드 블록입니다.

요청이 도착하면

제목: 문서에 넣은 대화
등장인물:
  web:
    그림: 서버
    이름표: 웹 서버
  db:
    그림: 데이터베이스
    이름표: 데이터베이스
컷:
  - 인물:
      - web
      - db
    대사:
      - 화자: web
        상대: db
        내용: 문서 안에서도 대화해요!
      - 화자: db
        내용: 같은 캐릭터를 다시 써도 좋아요.

응답을 기다리는 클라이언트

제목: 요청을 보내요
등장인물:
  browser:
    그림: 클라이언트
    이름표: 클라이언트
컷:
  - 인물:
      - 식별자: browser
        표정: 기쁨
        손모양: 인사손
        든소품: 요청
    대사:
      - 화자: browser
        내용: Hello, server!

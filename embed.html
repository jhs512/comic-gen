COMICS IN DOCUMENTS

설명 사이에, 작은 대화.

만화 코드 블록을 브라우저에서 렌더링합니다. 아래 그림은 각각 독립적인 코드 블록입니다.

요청이 도착하면

title: 문서에 넣은 대화
cast:
  web: {asset: server, label: 웹 서버}
  db: {asset: database, label: 데이터베이스}
panels:
  - actors: [web, db]
    dialogue:
      - {from: web, to: db, text: "문서 안에서도 대화해요!"}
      - {from: db, text: "같은 캐릭터를 다시 써도 좋아요."}

응답을 기다리는 클라이언트

title: 요청을 보내요
cast:
  browser: {asset: client, label: 클라이언트}
panels:
  - actors: [{id: browser, expression: happy, gesture: wave, holding: request}]
    dialogue: [{from: browser, text: "Hello, server!"}]

오류는 해당 블록에서만

잘못된 에셋을 참조해도 다른 만화는 정상적으로 표시됩니다.

cast: {missing: {asset: unknown}}
panels: [{actors: [missing]}]

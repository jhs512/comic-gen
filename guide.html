AUTHORING GUIDE · v0.2.1

첫 대사부터,
나만의 설명까지.

Comic Gen은 준비된 SVG 에셋을 YAML로 조합하는 브라우저 렌더러입니다. 세 캐릭터에 이름표·표정·대사를 더해 교육 자료, 기술 문서와 짧은 이야기를 만듭니다. 그림을 새로 생성하는 AI는 사용하지 않습니다.

빠른 시작문법과 기본값표정·손·소품배치SDK·저장문서 삽입오류 해결

1. 두 캐릭터의 대화 만들기

플레이그라운드에서 이 예제 열기 → 

title: 요청과 응답
cast:
  web: {asset: server, label: 웹 서버}
  db: {asset: database, label: DB}
panels:
  - actors: [web, db]
    dialogue:
      - {from: web, to: db, text: "데이터를 부탁해!"}
      - {from: db, to: web, text: "좋아, 바로 찾아볼게!"}

cast는 인물 사전, panels는 컷 목록입니다. 각 컷의 actors에 등장하는 인물을 적고 dialogue에 순서대로 대사를 넣으세요. YAML은 들여쓰기를 쓰므로 탭 대신 공백 두 칸을 권장합니다. 콜론·따옴표가 든 대사는 따옴표로 감싸거나 아래의 여러 줄 문법을 사용하세요.

2. 문법과 기본값

위치 항목 값과 기본값
최상위 title 선택 문자열. 기본 Comic Gen.
최상위 cast 필수 객체. 키가 인물 ID이며 같은 에셋도 여러 ID로 사용 가능.
최상위 panels 필수 목록. 1~30컷. 적은 순서대로 세로 배치.
cast의 인물 asset / label asset 필수: client, server, database. label 선택, 기본은 인물 ID.
컷 actors 필수, 1~3명. ID 문자열 또는 설정 객체. 한 컷에서 ID 중복 불가.
컷 dialogue / transfer 선택 목록. 기본은 빈 목록. 최대 20대사, 6개 전달 관계.
인물 설정 id 필수. cast에 선언한 인물 ID.
인물 설정 expression neutral(기본), happy, confused, sad, angry.
인물 설정 gesture / holding 선택. gesture: wave, point. holding: request, data, key.
인물 설정 x / y / scale x/y: 0~1, 기본 자동. scale: 0.5~1.25, 기본 1.
대사 from / to / text from과 text 필수. to 선택. 화자와 상대 모두 해당 컷의 actors에 있어야 함.
대사 x / y / fontSize x/y: 0~1, 기본 자동. fontSize: 12~32, 기본 18.
전달 from / to / prop 모두 필수. 서로 다른 인물 ID와 request, data, key 중 소품.

3. 표정·손·소품과 전달

actors:
  - {id: web, expression: happy, gesture: wave, holding: request}
  - {id: db, expression: confused}
transfer:
  - {from: db, to: web, prop: data}

holding은 인물이 들고 있는 물건, transfer는 인물 사이의 정적인 전달 표현입니다. 전달의 두 끝은 인물 근처에 붙습니다. 애니메이션이나 실제 네트워크 동작은 없습니다. 손 제스처와 holding을 생략하면 기본 손을 그리지 않으며, transfer를 쓰면 전달용 손이 표시됩니다. 이름표를 바꿔 서버를 선생님에 비유할 수도 있습니다.

4. 여러 컷과 수동 배치

같은 ID를 다음 컷의 actors에도 넣으면 이름표와 에셋을 재사용합니다. 표정·손·소품·좌표는 각 컷에서 지정합니다. 인물 x는 내부 여백을 제외한 가로 영역의 비율, y는 컷 높이의 비율입니다. 안전한 영역으로 제한되므로 입력한 비율과 최종 위치가 다를 수 있습니다. 대사 x는 말풍선 중심, y는 상단의 비율입니다. scale은 좁은 폭에 맞춘 기본 크기에 대한 배율입니다. 

actors:
  - {id: web, x: 0.25, y: 0.85, scale: 0.8}
  - {id: db, x: 0.75}
dialogue:
  - {from: web, to: db, text: "조금 작게 말할게!", x: 0.35, fontSize: 16}

인물끼리 겹치면 오류를 표시합니다. 수동 말풍선끼리의 겹침이나 전달 선이 다른 인물을 지나는 경우를 모두 자동 회피하지는 않습니다. 자동 배치부터 시작한 뒤 조금씩 조절하세요.

여러 줄 대사

dialogue:
  - from: web
    to: db
    text: |-
      첫 번째 줄이에요.
      두 번째 줄은 직접 나눴어요.

긴 대사는 브라우저 글꼴의 실제 폭을 측정해 자동 줄바꿈합니다. 한국어·영어 예제는 여기서 수정할 수 있습니다. 자동 번역 기능은 없습니다.

변화만 적는 네 컷

mode: before는 이전 컷의 인물 상태만 상속합니다. ID별로 지정한 설정을 덮어쓰고, 선택 필드의 null은 기본값으로 초기화합니다. 대사와 전달은 상속하지 않고 각 컷에 새로 적습니다. 첫 컷은 완전히 정의하세요. 

cast:
  web: {asset: server, label: 웹 서버}
  db: {asset: database, label: DB}
panels:
  - actors: [{id: web, expression: confused}, db]
    dialogue: [{from: web, to: db, text: "데이터가 있니?"}]
  - mode: before
    actors: [{id: db, expression: happy, holding: data}]
    dialogue: [{from: db, to: web, text: "찾았어!"}]
  - mode: before
    actors: [{id: db, holding: null}, {id: web, expression: happy}]
    transfer: [{from: db, to: web, prop: data}]
  - mode: before
    actors: [{id: web, holding: data, gesture: wave}]
    dialogue: [{from: web, to: db, text: "다음에도 함께하자!"}]

네 컷 예제 수정 →

  • actors 생략: 이전 인물의 순서·표정·손·holding·좌표·배율 유지.
  • 기존 ID는 부분 변경, 새 ID는 목록 뒤에 추가. ID 중복은 오류.
  • gesture/holding/x/y/scale/expression의 null은 제거 후 기본값 적용.
  • removeActors: [db]로 이전 인물 제거. 없는 ID는 오류.
  • actors: []는 전체 비우기이므로 최소 1명 조건 오류. 변경이 없으면 생략.
  • dialogue/transfer는 생략 또는 []이면 없음. 제공한 목록으로 대체.
  • cast·에셋·이름표는 전체 공유. 배경은 지원하지 않음.
  • mode: full 또는 mode 생략은 기존 전체 정의. 첫 컷 before는 오류.

스마트폰용 컷별 SVG

기본 화면·문서 삽입은 컷마다 독립 SVG를 세로로 나열합니다. phone은 compact 대비 실제 SVG 높이가 2배이며 PNG에도 같은 비율을 적용합니다. 캐릭터와 말풍선을 찌그러뜨리지 않고 내용 주변의 상하 여백을 늘립니다. x/y는 중앙의 기본 내용 영역을 기준으로 합니다. 명시한 width는 유지하며 height 옵션은 없습니다. 플레이그라운드에서 기존 비율을 선택할 수 있습니다.

5. 브라우저 SDK와 SVG·PNG 저장

최신 주소는 main 브랜치를 따르며 CDN 캐시로 반영이 지연될 수 있습니다. 특정 결과를 유지하려면 v0.2.1 같은 버전 고정 주소를 사용하세요. 

import { renderPanels, exportPng, downloadBlob }
  from 'https://cdn.jsdelivr.net/gh/jhs512/comic-gen@main/cdn/comic-gen.js';
await document.fonts.ready;
const result = renderPanels(source, {width: 720, panelFormat: 'phone'});
if (result.diagnostics.length) {
  console.error(result.diagnostics);
} else {
  document.querySelector('#preview').innerHTML = result.panels.map(panel => panel.svg).join('');
  const first = result.panels[0];
  downloadBlob(new Blob([first.svg], {type: 'image/svg+xml'}), 'panel-1.svg');
  const png = await exportPng(first, 2);
  downloadBlob(png, 'panel-1.png');
}

브라우저에서 module 스크립트로 실행하세요. source는 YAML 문자열이며 #preview는 결과를 넣을 요소입니다. 다운로드는 사용자가 버튼을 누르는 이벤트에서 호출하는 것을 권장합니다. width는 480~2400, font와 fontVersion도 지정할 수 있습니다. 독립 캐시가 필요하면 createRenderer(maxCacheBytes)를 사용하고 clearCache()로 비웁니다. 기본 메모리 캐시는 2MB이며 영구 저장되지 않습니다.

6. 문서·Markdown·CodePen에 삽입하기

renderPanels는 panels 배열에 index(0부터), svg, width, height, diagnostics, cache를 반환합니다. 실패하면 최상위 diagnostics와 빈 panels를 반환합니다. createRenderer에도 renderPanels가 있습니다. panelFormat은 phone(기본) 또는 compact입니다. renderComic와 renderer.render는 기존 통합 SVG·기본 compact를 유지하며, 새 결과의 svg는 선택적인 전체 저장에 사용할 수 있습니다. 

<pre data-comic><code>cast:
  a: {asset: server, label: 설명자}
panels:
  - actors: [a]
    dialogue: [{from: a, text: "문서 안에서도 설명해요!"}]
</code></pre>
<script type="module">
  import { renderCodeBlocks } from
    'https://cdn.jsdelivr.net/gh/jhs512/comic-gen@main/cdn/comic-gen.js';
  await document.fonts.ready;
  renderCodeBlocks();
</script>

CodePen의 HTML 영역에 그대로 붙여 넣을 수 있습니다. HTML에 넣는 대사의 &, <, >는 이스케이프하세요. Markdown의 comic 코드 블록을 pre > code.language-comic으로 변환하면 렌더링합니다. renderCodeBlocks(root)는 원하는 컨테이너만 처리할 수도 있습니다. 오류는 블록별로 표시됩니다. slog.gg의 $$ 문법은 해당 서비스 파서에 별도 연결해야 합니다.

7. 오류 해결과 현재 한계

  • 없는 캐릭터: cast의 ID와 actors의 ID가 같은지 확인하세요.
  • 화자·상대가 컷에 없음: from/to에 쓴 인물을 같은 컷의 actors에 넣으세요.
  • 알 수 없는 항목: 키 이름의 오타와 대소문자를 확인하세요.
  • 인물 겹침: x/y를 벌리거나 scale을 줄이세요. 자동 배치로 돌아가도 됩니다.
  • 이름표가 너무 김: 이름표는 두 줄 이내로 줄이세요.
  • 그림이 다르게 보임: SVG에 글꼴을 포함하지 않습니다. 동일한 픽셀 결과가 필요하면 PNG로 저장하세요.

입력은 100,000 문자, 각 텍스트는 10,000 문자 이내입니다. PNG 배율은 0.5~4, 최대 한 변 16,384픽셀·총 3,200만 픽셀입니다. 자동 경로 회피, 임의 에셋 업로드, 배경 에셋, AI 그림 생성, 계정 저장, CLI는 아직 지원하지 않습니다. 현재 자동 테스트는 Chromium에서 실행합니다.

# 07: 문서 코드 블록에서 만화 표시

**What to build:** 정적 문서 예제에서 코드 블록을 같은 브라우저 렌더러로 만화로 표시한다.

**Blocked by:** 01: 코드로 두 캐릭터의 대화를 그리고 SVG 저장.

**Status:** ready-for-agent

- [ ] 정적인 문서에서 만화 코드 블록이 렌더링된다.
- [ ] 같은 페이지의 여러 만화가 독립적으로 표시된다.
- [ ] 한 블록의 오류가 다른 블록을 망가뜨리지 않는다.
- [ ] 반복 연결 시 중복 표시되지 않고 렌더링 계산 서버가 필요 없다.

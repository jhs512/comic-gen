# 01: 코드로 두 캐릭터의 대화를 그리고 SVG 저장

**What to build:** 준비된 역할별 에셋과 표정·대사를 코드로 조합해 브라우저에서 편집하고 같은 장면을 SVG로 저장한다.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 짧은 선언 코드로 웹 서버와 DB를 표시하며 역할과 이름을 구분한다.
- [ ] 표정을 선택하고 생략하면 기본 표정을 사용한다.
- [ ] 코드 수정 시 미리보기가 갱신되고 같은 에셋의 복수 인물을 구분한다.
- [ ] 잘못된 문법·에셋·화자 참조는 수정 가능한 진단을 제공한다.
- [ ] 대사는 실행하지 않는 텍스트로 표시하고 브라우저에서 SVG 저장까지 검증한다.

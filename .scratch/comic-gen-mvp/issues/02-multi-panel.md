# 02: 여러 컷과 세 캐릭터의 대화 자동 배치

**What to build:** 같은 캐릭터를 여러 컷에서 재사용하며 대화 상대를 지정하고, 세 인물과 긴 대사를 좌표 없이 배치한다.

**Blocked by:** 01: 코드로 두 캐릭터의 대화를 그리고 SVG 저장.

**Status:** ready-for-agent

- [ ] 여러 컷에서 두세 인물을 겹치지 않게 배치한다.
- [ ] 화자와 대화 상대를 구분하고 잘못된 상대를 진단한다.
- [ ] 한국어·영어·혼합 대사가 줄바꿈되고 말풍선 안에 표시된다.
- [ ] 대사 순서가 읽기 순서로 표현된다.
- [ ] 미리보기와 SVG 저장에서 같은 결과를 검증한다.

# 03: 손 제스처와 소품 들기·건네기

**What to build:** 제스처와 소품 관계를 코드로 지정해 손은 필요한 장면에서만 표시하고 물건을 들거나 건네는 정적인 컷을 만든다.

**Blocked by:** 02: 여러 컷과 세 캐릭터의 대화 자동 배치.

**Status:** ready-for-agent

- [ ] 손은 기본적으로 생략하며 선택한 제스처를 표시한다.
- [ ] 인물이 소품을 들고 있는 모습을 표시한다.
- [ ] 소품을 주는 인물과 받는 인물을 구분한다.
- [ ] 잘못된 소품·제스처·전달 대상은 진단한다.
- [ ] 각 행동을 브라우저 미리보기와 내보낸 SVG에서 검증한다.

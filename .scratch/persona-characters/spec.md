# 사람이 설명하는 페르소나 만화

## 목표

빅데이터 전문가 김대리, 마케팅 팀장, 오사원이 같은 인물로 여러 컷에 등장해 질문·반론·설명으로 교육 개념을 풀어낸다. 기존 아이콘 만화의 문법과 SVG 결과, 동기·비동기 SDK와 선택형 뷰어를 유지한다.

## 구체 설계

`등장인물`은 인물 ID와 이름표를 공유한다. 새 `그림: 사람`은 준비된 SVG 부품으로 사람을 그리며, 인물별 `외형`은 만화 전체에서 유지한다. 컷의 `표정`, `손모양`, `든소품`, 대화 상대는 기존 문법으로 변화시킨다. 직무가 외형이나 표정을 결정하지 않는다.

`페르소나`는 직무·성격·말투를 담는 작성용 정보다. 렌더러는 직접 작성한 `대사.내용`을 표시한다. 페르소나로 대사를 생성하거나 해석해 표정을 정하지 않는다. 최상위의 선택형 `페르소나` 사전에 프로필을 선언하고 인물의 `페르소나`에 ID를 참조하거나, 인물 안에 프로필 객체를 바로 작성할 수 있다. 프로필은 외형·이름표를 포함하지 않는다.

| 위치     | 한글 / 영어          | 규칙                                                              |
| -------- | -------------------- | ----------------------------------------------------------------- |
| 최상위   | 페르소나 / personas  | 선택 프로필 사전. 키는 사용자가 정한 ID                           |
| 등장인물 | 그림 / asset         | 기존 세 그림 또는 사람 / human. 계속 필수                         |
| 등장인물 | 페르소나 / persona   | 선택 프로필 ID 문자열 또는 인라인 프로필 객체                     |
| 등장인물 | 외형 / appearance    | 사람에만 선택. 생략한 필드는 기본값 적용                          |
| 프로필   | 직무 / role          | 선택 문자열, 1~100자                                              |
| 프로필   | 성격 / personality   | 선택 문자열, 1~300자                                              |
| 프로필   | 말투 / speechStyle   | 선택 문자열, 1~300자                                              |
| 외형     | 피부색 / skinColor   | #RGB 또는 #RRGGBB. 기본 #f0c8a6                                   |
| 외형     | 머리모양 / hairStyle | 짧은머리/short, 단발/bob, 긴머리/long, 민머리/bald. 기본 짧은머리 |
| 외형     | 머리색 / hairColor   | #RGB 또는 #RRGGBB. 기본 #47362f                                   |
| 외형     | 옷 / outfit          | 셔츠/shirt, 재킷/jacket, 후드/hoodie. 기본 셔츠                   |
| 외형     | 옷색 / outfitColor   | #RGB 또는 #RRGGBB. 기본 #647bd6                                   |
| 외형     | 안경 / glasses       | boolean. 기본 false                                               |

프로필은 위 세 항목 중 하나 이상이 필요하다. 빈 프로필, 없는 참조, 잘못된 값·길이·형, 알 수 없는 항목과 한영 중복 항목은 한글 경로의 진단을 반환한다. 외부 이미지, 임의 SVG/JS/CSS, 프로필 상속 체인은 제공하지 않는다. 원문 안의 자유 문자열과 식별자는 번역하지 않는다.

## 재사용과 기본값

같은 `등장인물`과 프로필 사전을 여러 만화 원문에 재사용한다. SDK 호출 방식은 그대로이며 추가 전역 등록이나 외부 불러오기가 없다. JavaScript 호스트는 공유하는 cast/personas 객체와 각 이야기의 panels를 `JSON.stringify`로 조합한다. YAML에서는 같은 선언을 복사하거나 문서 안의 앵커를 사용할 수 있다. 읽기는 공유 객체를 변이시키지 않고 각 인물의 외형과 프로필을 독립 해석한다.

기존 client/server/database 인물은 새 필드나 기본값을 덧붙이지 않는다. 사람의 외형 기본값은 완전히 해석한다. 페르소나는 그림 캐시 조건에서 제외하고, 실제 사용하는 인물의 그림·이름표·외형만 포함한다. 페르소나 수정은 SVG와 캐시를 바꾸지 않고, 특정 인물 외형 수정은 그 인물이 등장하는 컷만 갱신한다.

## 구현 위치

- 모델·문법·검증: model/syntax/parse와 내부 인물 정의 모듈
- SVG 외형: human 모듈과 assets의 작은 인물 에셋 선택 함수
- 배치: 기존 얼굴·손·소품·말풍선/라벨 좌표를 유지하며 사람에만 외형 적용
- 예제: 김대리·마케팅 팀장·오사원의 4컷 회의와 같은 인물의 Mermaid 설명

## 검증 기록

`npm test -- --workers=3`: 65개 통과. 기존 57개와 사람·페르소나 공개 출력 검사 8개를 포함한다. 이전 SDK의 SVG 해시는 테스트에 고정하여 CI에서 네트워크 없이 검증한다. LLM 가이드의 6개 완전한 코드 블록도 두 컷 비율로 렌더링한다.

회의와 Mermaid 예제는 480/720/960px × 기본/모바일의 12종 조합에서 정상 렌더링되었다. PC 1440px·모바일 390px 뷰어의 양축 넘침 방지·200% 보기·다음 컷을 확인하고, 전체·개별 SVG와 PNG를 직접 저장하여 가독성을 확인했다. 큰 뒷 컷 때문에 작은 앞 컷이 함께 보이는 경우도 처음 열 때 1컷을 표시하도록 보정했다.

실행 가능한 원문은 이 디렉터리의 `meeting.yaml`과 `diagram.yaml`이다. 같은 등장인물·프로필 사전을 공유하며 컷 내용만 바뀐다.

## 한계

컷당 인물은 계속 최대 3명이다. 외형은 정적인 상반신 SVG이며 자유 포즈·배경·애니메이션·대사 자동 생성은 포함하지 않는다. 외부 서비스가 vendor SDK를 사용하면 새 사람 문법을 쓰기 전에 v0.6.0 이상으로 갱신해야 한다.

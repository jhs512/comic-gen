# 실제 그림으로 배우는 안내와 명확한 손 제스처

Status: ready-for-agent

안내에 같은 source의 실제 그림·작성 코드·읽는 포인트를 제공하고 컷 이동·전체 보기를 연결한다. 갤러리에 의미가 다른 상황 예제를 추가한다. 손이 설명 대상의 실제 방향을 가리키게 하고 칠판을 가리키는 위쪽 손을 추가한다.

## Comments

- 2026-10-04: 사용자의 원래 음성 요청을 읽어 범위를 확인했다. 문법 설명의 정보량을 늘리기보다 그림에서 의도가 읽히는 실제 예제를 우선한다.
- 기존 v0.7.7의 17예제·35컷을 실제 작은 화면에서 읽고 레퍼런스 조사·시각 점검·안내 구현을 병행한다.
- 2026-10-04 구현: 안내 6곳에 동일 소스의 실제 그림·작성 코드·읽는 포인트·컷 이동·크게 보기를 연결했다. 새 상황 5개·13컷을 추가해 갤러리는 22예제·48컷이다.
- 손 제스처는 첫 대화 상대의 실제 배치에 맞춰 좌우를 가리키며, 위가리키는손(point-up)은 칠판을 향한다. 오른쪽을 가리키면서 소품을 들면 반대 손을 사용하고 전달 손과 겹쳐 물리적인 손이 늘어나지 않는다. 열쇠 이야기의 소유권은 보유 → 전달 중 → 상대의 보유로 나눴다.
- 검증: 프로덕션 빌드·타입 검사와 Playwright 82개 통과. 실제 갤러리 48컷·안내 16컷을 1280/390/320px에서 캡처해 192개 컷 화면을 검토했고 오류·넘침·진단·모달 실패는 0건이었다. 안내 6개 모달은 총 18회 열기/닫기 및 포커스 복원을 확인했다. 손의 검지·손목·피부·소매·PNG·문법은 별도 90가지 렌더 및 한영 6가지 출력으로 확인했다.
- 320px에서 긴 API 이름 묶음이 본문 밖으로 넘치는 것을 발견해 본문 단어 줄바꿈으로 해결했다. 기존 갤러리 회귀 검사의 예제 수는 22개로 갱신했다.

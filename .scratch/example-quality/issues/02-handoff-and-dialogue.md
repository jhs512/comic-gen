# 건네기 표현과 예제 대사의 자연스러움

Status: ready-for-human

01의 개선 후에도 사람이 실제 그림을 보고 의도를 오해한 부분을 고친다. 전달은 빈 주먹 두 개와 떠 있는 소품이라 "전선이 꽂힌 모양"으로 읽혔다. 갤러리 예제에는 어색한 대사, 같은 인물의 존댓말·반말 혼용, 대화 상대 반대쪽으로 흔드는 인사손, 든소품과 전달을 한 컷에 함께 써서 두 개로 보이는 소품이 남아 있었다. 사람의 인사손·가리키는손은 얼굴에 비해 너무 컸다.

## Comments

- 2026-10-04: 사용자가 실제 화면 캡처로 네 곳을 지적했다. 전달의 빈 주먹, actions 예제의 중복 봉투·인사손에 꽂히는 화살표, cache 첫 대사("처음 요청한 데이터가 있나요?"), 사람의 큰 인사손과 가리키는손이다. 지적된 곳만 고치지 않고 22개 예제의 대사·표정·손을 모두 다시 읽었다.
- 전달: 아이콘은 손 없이 소품을 화살표 위에 얹는다. 사람은 주는 사람이 펼친 손바닥에 소품을 올려 내밀고, 받는 사람은 손을 오므려 펼친다. 같은 두 인물 사이의 여러 소품은 화살표를 따라 나누고, 짧은 화살표에서는 바로 위로 올린다. 화살표는 인물 위에 그리므로 손과 겹치지 않게 끝을 띄운다.
- 사람의 손: 인사손 0.6배, 가리키는손 0.72배와 짧은 검지. 위가리키는손은 가운데 손가락을 세운 것으로 오해되지 않도록 머리 쪽 가장자리에서 검지를 세우고 엄지를 앞에 둔 ☝ 모양으로 다시 그리고, 팔꿈치를 굽혀 머리 높이에 둔다.
- 예제: actions·auth를 든소품 → 전달 → 받은 결과로 나눴다. cache를 미스 → 첫 전달 → 적중의 3컷으로 다시 썼다. before·welcome·gestures의 인사손은 v0.8.0 손방향으로 상대 쪽을 향한다. basic·retry의 맞지 않는 어리둥절 표정, expressions·manual의 말투 혼용, lesson·handoff·welcome·persona-diagram의 모호한 대사, long-text의 빈 곳 가리키기를 고쳤다.
- 검증: 모든 공개 예제에서 든소품과 같은 소품의 동시 전달, 손모양 쪽으로 들어가는 전달 화살표가 없는지 확인하는 회귀 검사를 추가했다. 기존 검사의 "화살표 끝은 손바닥 안" 기준을 "손 옆의 작은 틈 또는 아이콘 몸통 가장자리"로 바꾸고, 사람 손 크기 기준을 줄인 크기에 맞췄다. Playwright 84개 통과. 480px 일반·모바일 컷으로 변경 예제를 직접 확인했다.
- 2026-10-04 (v0.8.2): 사용자가 공개 화면에서 손바닥 위의 열쇠와 받는 손이 부자연스럽다고 지적했다. 작은 크기에서 위로 편 손바닥은 납작한 판, 오므린 손은 갈고리로 읽혔다. 작은 크기에서도 잘 읽히는 두 모양을 재사용한다. 주는 사람은 든소품과 같은 주먹으로 소품을 쥐고(엄지는 소품 앞) 내밀며, 화살표는 소품 너머에서 시작한다. 받는 사람은 인사손의 다섯 손가락 손을 상대 쪽으로 기울여 뻗는다. 곡선 전달 PNG 검사는 주는 사람의 엄지가 소품 앞에 있는 것을 의도된 가림으로 비교한다.
- 2026-10-04 (v0.8.3): 사용자가 위가리키는손의 팔이 너무 길다고 지적했다. 팔꿈치를 몸 옆에 두고 아래팔을 짧게 해 손을 얼굴 옆(귀 높이)에 둔다. ☝ 자세의 손끝은 머리 위가 아니라 눈보다 위에 있으면 충분하므로 사람의 위쪽 도달 기준을 바꿨다.
- 2026-10-04 (v0.8.4): 사용자가 반대쪽 기본 손은 몸에 붙은 주먹이라 위가리키는손의 팔이 상대적으로 너무 길어 보인다고 지적했다. 상반신 그림에서는 위팔을 몸에 가리고 짧고 굵은 아래팔만 어깨 가장자리에서 세워 손을 뺨 높이에 둔다. 같은 문제가 있던 사람의 인사손 팔도 같은 구조로 바꿨다. 사람의 위쪽 손끝 기준은 눈(y=-16)보다 위로 완화했다.
- 2026-10-04 (v0.8.5): 사용자가 인사손의 팔도 조금 더 짧게 해 달라고 요청했다. 아래팔 끝을 10만큼 낮춰 손을 눈 높이 근처에 두고 흔드는 선도 함께 내렸다.

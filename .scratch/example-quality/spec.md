# 안내 예제와 표현 의도의 품질 개선

사용자는 안내 페이지에 예제를 더 넣고, 사람이 봤을 때 어색하거나 표현 의도가 전달되지 않는 부분을 여러 레퍼런스를 조사해 개선하도록 요청했다. 충분히 공들여 진행하고 데스크톱·휴대폰 크기의 실제 그림으로 검증한다.

안내의 주요 문법에 실제 렌더된 그림과 같은 작성 코드를 함께 둔다. 새 예제는 인사·설명 방향·질문과 이해·소품 소유권 변화·감정 변화처럼 사람에게 읽히는 차이를 보여주며, 기존 갤러리 ID와 안내 앵커를 보존한다.

현재 관찰한 우선 문제는 오른쪽 상대에게 말하면서 왼쪽을 가리키는 손, 칠판 설명인데 바깥을 가리키는 손, 결의 대사와 화남 표정의 불일치다. A의 자연스러운 다섯 손가락과 기존 외형 설정은 유지한다. 여러 동작이 한 손에 겹치거나 든 소품과 이동 소품이 복제처럼 보이지 않도록 점검한다.

레퍼런스 근거는 references.md, 실제 렌더 검증 자료는 작업 외부의 comic-gen-example-quality 폴더에 남긴다. 별도 C:/works/comic-gen의 미공개 v0.8.0 작업은 수정하지 않는다. 검증이 끝나면 기존 푸시 요청에 따라 공개 배포까지 확인한다.

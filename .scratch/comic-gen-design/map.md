# IT 교육용 Comic Gen 설계 지도

Label: wayfinder:map

## Destination

IT 교육용 만화를 코드로 빠르게 작성하고 SVG 및 PNG로 출력하며 문서에 삽입할 수 있는 도구의 구현 가능한 첫 버전 명세를 정한다. 문법, 렌더링, 에셋 재사용과 배포 경계를 결정하는 것이 이번 설계의 도착점이다.

## Notes

- 현재 산출물: [Comic Gen 첫 버전 명세](spec.md). 사용자의 to-spec 요청으로 합의한 요구와 구현 제안을 구분해 작성했다. 문법 프로토타입과 남은 상세 결정이 완료됐다는 의미는 아니다.
- 설계 단계다. 제품 구현과 배포는 후속 작업이다.
- 매 세션 wayfinder와 관련 티켓 유형의 스킬을 읽는다. 대화형 결정에는 grilling과 domain-modeling을 적용한다.
- 사용 맥락: IT 교육 내용을 간단한 캐릭터와 대사로 설명하는 만화.
- 사용자 선호: 캐릭터, 표정, 행동, 대사 중심으로 빠르게 작성하고 컷과 말풍선은 자동 배치한다. 필요할 때 직접 조정할 자유도를 둔다.
- 최신 사용자 결정: 첫 버전은 준비한 에셋 라이브러리를 코드로 조합한다. 코드 안에서 새 그림을 직접 정의하는 기능은 제외한다. 초기의 직접 그림 정의 요구를 대체한다.
- 사용자는 클라이언트 렌더링과 캐시를 제안했고, 이에 기반한 명세 작성을 요청했다.
- 참고: [ComicForge](https://github.com/mojzis/comicforge).
- 지향점: PlantUML 같은 텍스트 작성 경험과 slog.gg에서 사용자가 설명한 문서 블록 렌더링 경험. 실제 slog.gg 연동 가능 여부는 아직 검증하지 않았다.
- 이 작업 디렉터리는 Git 저장소가 아니다. 조사 결과는 이 로컬 이슈 트래커 아래 보관하며, 연구 브랜치를 만들기 위해 임의로 Git을 초기화하지 않는다.

## Decisions so far

- [ComicForge 구조와 문서 삽입 적합성 조사](issues/01-comicforge-fit.md): SVG 합성·말풍선 배치는 참고하고 직접 그림 정의·인물/컷 자동 배치·브라우저 연동은 별도 설계하며, 코드 재사용 전 라이선스를 확인한다.
- [교육 만화의 최소 작성 경험 결정](issues/02-authoring-experience.md): 준비한 에셋으로 두세 캐릭터의 역할·표정·대사·대화 상대·손 제스처·소품을 표현하며, 역할별 몸체를 기본 시각 방향으로 삼는다.

## Not yet specified

- 자동 배치와 수동 수정 사이의 구체적인 표현 방식.
- 재사용 에셋의 변형, 표정·포즈 확장, 버전과 참조 방식.
- 렌더링 환경과 브라우저·CLI·문서 플러그인 사이의 책임 경계.
- 사용자가 제안한 클라이언트 렌더링과 캐시의 구체적인 정책: 에셋과 완성 결과의 재사용, 코드·에셋·글꼴·출력 크기 변경 시 갱신, 메모리 및 영속 저장의 범위. 메모리 캐시부터 시작하는 것은 현재 추천안이며 구현하거나 확정하지 않았다.
- 순수 벡터 SVG와 래스터 포함 SVG의 지원 범위.
- 다양한 언어의 대사, 글꼴과 말풍선 줄바꿈.
- 외부 에셋을 불러오는 규칙과 안전한 문서 렌더링.
- 첫 버전에서 제공할 예제 캐릭터 및 교육 시나리오.
- 구현 순서와 완료를 판정할 대표 예제.

## Out of scope

- 이번 설계 세션에서 완성 제품을 구현하거나 배포하는 작업.
- 첫 버전의 코드 내 직접 그림 정의와 에셋 제작 도구.
- 사용자 승인 없이 slog.gg 또는 다른 외부 서비스를 수정하는 작업.

# 짧은 코드와 재사용 그림 정의의 작성 경험 검증

Type: prototype
Status: open
Blocked by: 02

## Question

역할별 몸체와 이름표를 가진 캐릭터 두세 명의 대화를 얼마나 짧게 작성할 수 있는가? 대표 코드 예제를 보여주고 컷 구분, 표정, 대사, 대화 상대, 선택적인 손 제스처, 들고 있는 소품과 건네주는 소품을 표현하는 문법을 사용자와 검증한다. 최신 사용자 결정에 따라 준비한 에셋 참조와 조합에 한정하고 인라인 새 그림 정의는 제외한다. 특정 언어 문법이나 외부 에셋 저장소를 미리 확정하지 않는다.

시각 기준은 [동그란 캐릭터 시각 초안](../prototype-round-characters.svg)이며 제품 코드 대신 일회성 문법·렌더링 예제로 반응을 확인한다.

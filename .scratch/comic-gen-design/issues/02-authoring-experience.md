# 교육 만화의 최소 작성 경험 결정

Type: grilling
Status: resolved

## Question

사용자가 IT 개념을 설명하는 짧은 만화를 작성할 때 직접 적어야 할 최소 정보는 무엇인가? 캐릭터와 대사 중심의 자동 배치를 기본으로 하되, 컷 구분·행동·표정·그림 정의·재사용 참조를 어떤 수준까지 첫 버전에 포함할지 사용자와 결정한다. 실제 문법 확정에 앞서 대표 교육 예제를 함께 정한다.

## Comments

사용자는 특정 교육 주제보다 표현 범위를 먼저 제시했다. 귀여운 동그라미 기반 캐릭터에 표정이 있고, 한 컷에 두세 명이 대화하면 충분하다. 사람 같은 팔다리는 기본으로 필요하지 않으며, 손은 제스처나 물건을 주고받을 때만 작은 원으로 표현한다. 자유롭게 확장할 수 있으면서 간단한 캐릭터를 미리 만들어 빠르게 반복 사용하는 경험을 원한다.

[동그란 캐릭터 시각 초안](../prototype-round-characters.svg)은 이 표현 범위를 확인하기 위한 일회성 참고 그림이다. 사용자 확인 전에는 최종 디자인으로 확정하지 않는다.

사용자는 초안의 귀여운 모습은 수용 가능하지만, 각 캐릭터가 어떤 IT 개념인지 알아볼 수 있어야 한다고 지적했다. 이름표와 역할 아이콘을 더한 초안으로 수정했고, 사용자는 이 방향을 “나쁘지 않아”라고 평가했다.

## Answer

첫 버전의 대표 사용 경험은 한 컷에 두세 캐릭터가 표정과 대사로 IT 개념을 설명하는 것이다. 기본은 귀엽고 단순한 캐릭터다. 사용자가 뒤이어 “두 번째 게 좋아”라고 선택했으므로, DB는 원통·서버는 상자처럼 몸체 자체도 역할에 맞추는 방향을 적용한다. 이름표와 역할 아이콘도 개념 구분에 사용할 수 있다. 손은 평소 생략하고 제스처나 물건 전달이 필요할 때 작은 원으로 추가한다. 기존 동그란 몸 초안은 시각 탐색 자료로 보관하며 선택한 몸체 변형을 아직 반영한 그림은 아니다.

작성자는 등장인물의 역할, 표정, 대사, 대화 상대와 필요한 손 제스처를 표현한다. 소품을 들거나 특정 상대에게 건네는 상황도 표현한다. 컷과 말풍선 자동 배치를 기본으로 하고 수동 조정의 여지를 둔다. 최신 사용자 결정에 따라 첫 버전은 준비한 에셋 라이브러리를 코드로 조합하며, 코드에서 직접 새 그림을 정의하는 기능은 제외한다. 정확한 문법, 기본값과 에셋 참조 규칙은 별도로 검증한다.

특정 교육 주제는 사용자에게 없었다. 시각 초안의 웹 서버와 DB 대화는 참고 예제이며 고정된 교육 콘텐츠 요구사항이 아니다.

[이름표와 역할 아이콘을 적용한 동그란 캐릭터 시각 초안](../prototype-round-characters.svg)을 기본 시각 방향의 참고 자료로 남긴다. 완성된 엔진의 출력이나 전체 디자인의 최종 승인으로 취급하지 않는다.

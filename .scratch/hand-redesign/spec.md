# 손 제스처 재설계

사용자 요청: v0.7.5의 인사손이 이상해 보이므로 좋은 레퍼런스를 충분히 살펴보고 대대적으로 업데이트한다.

최초 범위는 손·팔·손 제스처 전반이었으며, 사용자가 A(자연스러운 다섯 손가락)를 선택했다. 이후 사용자 요청에 따라 캐릭터 본체·표정·소품·말풍선·갤러리까지 전체적인 표현 품질을 점검하고 개선한다. 외형 설정, 작성 문법과 공개 SDK API는 유지한다. 인사손, 가리키는손, 소품을 드는 손과 전달하는 손을 일관된 형태로 정리한다.

현재 문제는 같은 길이의 평행한 손가락, 부자연스러운 엄지와 손목, 겹친 손 잔상, 사람의 팔 연결 누락, 같은 쪽 손의 중복이다. 움직임은 정적인 SVG·PNG에서도 읽혀야 한다.

먼저 공식 에셋 라이브러리의 실제 이미지를 비교하고 기존 갤러리의 실제 캐릭터에 3개 시안을 적용한다. 실제 모바일 크기와 PNG에서 비교한 결과를 바탕으로 최종 형태를 구현한다. 레퍼런스의 원본 path를 복사하지 않고 프로젝트의 선과 색상에 맞게 직접 그린다.

별도 C:/works/comic-gen 체크아웃의 미공개 작업은 수정하지 않는다.

갤러리에서는 실제 작은 화면에서도 대사와 컷 전체가 읽혀야 한다. 한 컷씩 이동하고 크게 보기로 전체 만화를 읽을 수 있게 한다. 사용자의 마지막 요청에 따라 검증이 끝나면 푸시하고 공개 배포를 확인한다. 전체 표현 개선은 v0.7.6, 최종 소품 겹침·가림 보정은 v0.7.7에 반영한다.

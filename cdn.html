CDN으로 만화 넣기

이 페이지는 v0.4.0 고정 CDN에서 SDK를 불러옵니다. 컷 안 다이어그램을 그릴 때만 Mermaid를 추가로 불러옵니다. 

제목: CDN에서 불러온 만화
등장인물:
  client:
    그림: 클라이언트
    이름표: 방문자
  server:
    그림: 서버
    이름표: 웹 서버
컷:
  - 인물:
      - 식별자: client
        표정: 기쁨
      - server
    대사:
      - 화자: client
        상대: server
        내용: 설치 없이 문서에 만화를 넣었어!
      - 화자: server
        상대: client
        내용: 그림은 네 브라우저에서 만들고 있어.
    다이어그램:
      종류: 머메이드

        sequenceDiagram
          participant 방문자
          participant 서버 as 웹 서버

          서버-->>방문자: 응답

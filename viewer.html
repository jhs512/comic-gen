일반 script 한 번과 pre language="comic-gen"만 사용하세요. viewer 속성은 PC 가로 스크롤, 모바일 탭 전체 화면을 켭니다. 아래는 자동 삽입 번들로 실제 그린 예제입니다.

직접 바꿔보세요

코드를 수정하고 적용하세요. 각 컷의 소품 동작도 바꿀 수 있습니다.

일반 삽입 — 세로 컷

cast: {a: {asset: client, label: 클라이언트}}
panels:
  - actors: [a]
    actions: [{actor: a, type: receive, prop: data}]
    dialogue: [{from: a, text: "외부에서 받은 데이터!"}]

복사해서 쓰는 HTML

전체 문법과 완전한 HTML 예제 (Markdown)

<script defer src="https://cdn.jsdelivr.net/gh/jhs512/comic-gen@main/cdn/comic-gen.auto.js"></script>
<pre language="comic-gen" viewer>
cast: {a: {asset: server}}
panels:
  - actors: [a]
    dialogue: [{from: a, text: "첫 컷"}]
  - mode: before
    dialogue: [{from: a, text: "다음 컷"}]
</pre>
